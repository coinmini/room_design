# Room Design MVP Web

React、TypeScript 与 Vite 实现的 V0.6 本地操作台，默认入口为“AI 设计工作流”。阶段 1、2
不再只是占位或独立页面：可在同一工作台完成识别校正、AI 平面布局生成与人工批准；阶段
3～5 继续生成彩平、轴侧与分空间效果图，阶段 6～8 明确标记为规划中。

工作台支持：

- 阶段 01 上传一次原始平面图，识别并校正功能区、墙体、门窗、家具和尺寸；
- 阶段 01 批准后，原图、尺寸和 `semanticLayout` 自动传递给阶段 02；
- 阶段 02 生成并审批 AI 家装平面布局，批准图片成为家具视觉权威；
- 阶段 02 不使用其他项目的完整户型参考图，只把当前功能区标注专业化、家具化和规范制图；
- 房间、墙体和门窗仍由阶段 01 的确认语义作为结构锁；
- 批量选择四种彩平或三种轴侧概念变体；
- 阶段 4、5 上传已批准彩平图；
- 按稳定 room ID 批量选择分空间效果图；
- 轮询后台任务、显示部分成功／失败项，并将结果归入“我的资产”。

AI 工作流资产生成后仍是 `review_required`，需要在资产中批准一个成功变体，才能作为后续
AI 阶段的父资产。轴侧结果是概念角度，不是可旋转的真实三维相机。

```bash
cd /Users/bolin/Documents/AI/room_design/apps/web
npm run dev -- --host 127.0.0.1
```

默认请求 `http://127.0.0.1:8000`。如需修改，可复制 `.env.example` 为 `.env.local` 并设置 `VITE_API_URL`。

旧版户型工作室和白模实验默认隐藏，仅在设置
`VITE_SHOW_LEGACY_TOOLS=true` 时显示。AI
多材质替换仍是独立蒙版编辑工具，不代表阶段 6～8 已经完成。Web 不持有 Kuyao API Key，
也不直接访问 8189、ComfyUI 或 Blender。
